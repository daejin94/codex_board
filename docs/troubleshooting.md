# 환경 제한 및 문제 해결 노트

## PR 생성이 보이지 않는 이유
- 현재 작업은 로컬 저장소에만 커밋되며, 실제 원격 GitHub 저장소로 푸시하거나 PR을 자동 생성하는 단계가 없습니다.
- 본 환경의 `make_pr` 도구는 PR 제목/본문을 기록하는 용도이며, 원격 저장소에 직접 PR을 생성하는 기능이 아닙니다.

## npm 403 오류 원인
- `npm install` 또는 `npm create` 실행 시 `registry.npmjs.org`로의 요청이 `403 Forbidden`으로 차단되었습니다.
- 이는 실행 환경의 네트워크/레지스트리 정책 제한으로 인해 발생한 것으로 보이며, 해당 제약이 해제되지 않는 한 패키지 설치가 실패합니다.
