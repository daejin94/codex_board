# 결정 기록

## 2026-02-05
- UserGrant 컬럼명을 `ROLE_NAME`, `ROLE`로 유지하기 위해 JPA에서 명시적으로 컬럼명을 지정함. 대문자 컬럼을 사용하는 경우 따옴표가 필요하므로 `globally_quoted_identifiers` 설정을 활용한다.
- 개발 환경에서 스키마를 자주 재생성할 수 있도록 `ddl-auto`를 `create-drop`으로 변경한다.
- 역할 매핑 구조를 단순화하기 위해 `User`가 `role_id`로 `UserGrant`를 참조하도록 변경한다.
- 게시글 저장은 `POST /api/posts`로 단일 엔드포인트를 제공하고, 작성자는 JWT의 subject(userId)를 사용한다.
- 일반 게시글 조회는 `GET /api/posts?page=&size=`로 최신순 페이징 조회하며, 프론트는 10개 단위 무한 스크롤을 사용한다.
- 게시글 관련 API(작성/조회/인기)는 인증 필수로 설정하고, 프론트 요청에 JWT 토큰을 포함한다.
- 추천은 게시글-사용자 단위로 1회만 가능하며, 토글 방식으로 취소를 지원한다. 인기 게시글은 추천수 20 이상만 대상으로 정렬 옵션을 제공한다.
- 추천 카운트는 Post의 `like_count` 컬럼으로 관리하며, 응답에 `liked` 플래그를 포함한다.
- 저장소 내 불필요한 산출물과 민감 정보 노출을 막기 위해 Node/Gradle/IDE/OS/환경 파일을 포함한 기본 .gitignore 규칙을 추가한다.
- 로컬 실행 온보딩을 개선하기 위해 README에 실행 방법/환경설정/인프라 기동 가이드를 추가한다.
- 커밋 컨벤션의 가독성을 위해 README 인코딩을 UTF-8로 정리한다.
